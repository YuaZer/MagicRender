# MagicRender Motion Trajectory Config Structure

This document defines the JSON shape used to author Unity-style motion trajectory effects: Trail and Beam.

The config is designed for non-programmers. Field names describe visible results, defaults are conservative, and every expensive value is clamped by the loader.

## File Location

Effect files live under:

```text
config/magicrender/effects/
```

Example files generated by the mod:

```text
config/magicrender/effects/dash_trail.json
config/magicrender/effects/mana_link.json
```

Existing files are not overwritten by default generation. If an old config already exists, edit it manually or remove it and let the mod regenerate defaults on the next run.

## Top Level Shape

```json
{
  "version": 1,
  "id": "magicrender:dash_trail",
  "enabled": true,
  "group": "combat",
  "durationTicks": 30,
  "importance": "normal",
  "visibility": {
    "drawDistance": 64,
    "hideWhenShadersConflict": false
  },
  "components": {
    "trail": {},
    "beam": {}
  }
}
```

Meaning:

- `id`: stable effect id used by code and commands.
- `enabled`: master switch for this effect.
- `group`: links to `effect_groups.json`; useful for disabling a whole category.
- `durationTicks`: effect instance lifetime. Trail points may fade earlier through `trail.lifetimeTicks`.
- `importance`: `low`, `normal`, or `high`; later used when limits force dropping effects.
- `visibility.drawDistance`: maximum render distance in blocks.
- `visibility.hideWhenShadersConflict`: manual compatibility switch. It is not auto-disabled just because Iris or Sodium exists.

## Trail Component

Trail is a history effect: it samples a moving anchor over time, then renders the previous positions as a fading ribbon.

```json
{
  "components": {
    "trail": {
      "enabled": true,
      "style": "ribbon",
      "texture": "magicrender:textures/effect/trail_soft.png",
      "renderMode": "face_camera",
      "lifetimeTicks": 16,
      "maxPoints": 32,
      "minSampleDistance": 0.08,
      "maxSegmentLength": 0.5,
      "maxInsertedPointsPerTick": 4,
      "sampleEveryTick": true,
      "width": {
        "start": 0.45,
        "end": 0.0
      },
      "color": {
        "start": "#88E6FFFF",
        "end": "#2266FFFF"
      }
    }
  }
}
```

Fields:

- `enabled`: independent switch for Trail.
- `style`: user-facing style label. Current renderer treats it as metadata.
- `texture`: texture resource id. Invalid or blank values fall back to a safe white texture.
- `renderMode`: `face_camera` for most magic trails, `world_up` for ground-like traces.
- `blendMode`: `additive` for energy/glow-like trails, `alpha` for smoke or soft translucent trails.
- `lifetimeTicks`: how long each sampled point remains visible.
- `maxPoints`: maximum stored points per trail.
- `minSampleDistance`: minimum movement before adding a point.
- `maxSegmentLength`: inserts intermediate points for fast movement so the trail does not break apart.
- `maxInsertedPointsPerTick`: safety limit for interpolation work.
- `sampleEveryTick`: when true, samples once per tick even if movement is small.
- `width.start` / `width.end`: visible ribbon width from fresh point to old point.
- `color.start` / `color.end`: ARGB hex color from fresh point to old point.
- `motion.mode`: `follow`, `orbit`, or `helix`. This only affects entity anchors.
- `motion.radius`: orbit radius around the entity.
- `motion.angularSpeed`: degrees per tick around the entity.
- `motion.verticalAmplitude`: vertical wave height for `helix`.
- `motion.verticalSpeed`: vertical wave degrees per tick for `helix`.
- `motion.phase`: phase offset in degrees, useful when spawning multiple trails around one entity.

Conservative ranges enforced by parsing:

```text
lifetimeTicks: 1..200
maxPoints: 2..128
minSampleDistance: 0.01..4.0
maxSegmentLength: 0.05..8.0
maxInsertedPointsPerTick: 0..8
width.start/end: 0.01..8.0
motion.radius: 0.0..16.0
motion.angularSpeed: -72.0..72.0
motion.verticalAmplitude: 0.0..16.0
motion.verticalSpeed: -72.0..72.0
```

## Magic Circle Component

Magic circle is a world-space procedural ring. It does not require a texture in the first implementation.

```json
{
  "components": {
    "magicCircle": {
      "enabled": true,
      "style": "arcane_gate",
      "radius": 1.65,
      "color": "#CCFFD24A",
      "thickness": 0.055,
      "segments": 128,
      "facing": "face_camera",
      "rotationSpeed": 1.2,
      "innerRadiusScale": 0.68,
      "glyphs": 18,
      "blendMode": "additive"
    }
  }
}
```

Fields:

- `enabled`: independent switch for Magic Circle.
- `style`: user-facing style label.
- `radius`: outer circle size.
- `color`: ARGB hex color.
- `thickness`: ring thickness.
- `segments`: circle smoothness.
- `facing`: `face_camera` for portal/gate-like circles, `horizontal` for ground circles.
- `rotationSpeed`: degrees per tick.
- `innerRadiusScale`: inner ring radius relative to the outer radius.
- `glyphs`: number of procedural tick marks around the circle.
- `blendMode`: `additive` or `alpha`.

Conservative ranges:

```text
radius: 0.1..32.0
thickness: 0.01..2.0
segments: 16..256
rotationSpeed: -16.0..16.0
innerRadiusScale: 0.1..0.95
glyphs: 0..64
```

## Beam Component

Beam is a live connection: it rebuilds a ribbon between two anchors every frame.

```json
{
  "components": {
    "beam": {
      "enabled": true,
      "style": "mana",
      "texture": "magicrender:textures/effect/beam_mana.png",
      "segments": 8,
      "noise": 0.08,
      "width": {
        "start": 0.18,
        "end": 0.08
      },
      "color": {
        "start": "#AAFFFFFF",
        "end": "#4488FFFF"
      }
    }
  }
}
```

Fields:

- `enabled`: independent switch for Beam.
- `style`: user-facing style label.
- `texture`: texture resource id.
- `segments`: number of subdivisions between start and end.
- `noise`: world-space random offset strength for lightning or unstable mana lines.
- `width.start` / `width.end`: beam width along its length.
- `color.start` / `color.end`: ARGB hex color along its length.

Conservative ranges:

```text
segments: 1..64
noise: 0.0..4.0
width.start/end: 0.01..8.0
```

## Entity Arcane Stream Example

This approximates the reference image with one helix trail plus one face-camera magic circle. It is still a first-layer world-space effect: no screen-space bloom or offscreen framebuffer is required.

```json
{
  "version": 1,
  "id": "magicrender:entity_arcane_stream",
  "enabled": true,
  "group": "combat",
  "durationTicks": 80,
  "importance": "high",
  "visibility": {
    "drawDistance": 96,
    "hideWhenShadersConflict": false
  },
  "components": {
    "trail": {
      "enabled": true,
      "style": "helix_stream",
      "lifetimeTicks": 42,
      "maxPoints": 96,
      "minSampleDistance": 0.03,
      "maxSegmentLength": 0.28,
      "maxInsertedPointsPerTick": 4,
      "sampleEveryTick": true,
      "renderMode": "face_camera",
      "blendMode": "additive",
      "motion": {
        "mode": "helix",
        "radius": 0.9,
        "angularSpeed": 16.0,
        "verticalAmplitude": 0.42,
        "verticalSpeed": 10.0,
        "phase": 0.0
      },
      "width": {
        "start": 0.24,
        "end": 0.02
      },
      "color": {
        "start": "#FFF6B640",
        "end": "#22FF4FB8"
      },
      "texture": "minecraft:textures/misc/white.png"
    },
    "magicCircle": {
      "enabled": true,
      "style": "arcane_gate",
      "radius": 1.65,
      "color": "#CCFFD24A",
      "thickness": 0.055,
      "segments": 128,
      "facing": "face_camera",
      "rotationSpeed": 1.2,
      "innerRadiusScale": 0.68,
      "glyphs": 18,
      "blendMode": "additive"
    }
  }
}
```

Spawn both parts on an entity:

```kotlin
val anchor = TrailAnchor.Entity(entity.id, Vec3(0.0, 1.2, 0.0))
MotionEffectManager.spawnTrail("magicrender:entity_arcane_stream", anchor)
MagicCircleManager.spawn("magicrender:entity_arcane_stream", anchor)
```

For multiple intertwined strands, create several effect files with different `motion.phase`, `color`, and `width`, then spawn them on the same entity.

## Client Bind Commands

Client-side test commands can bind effects to the entity under the player's crosshair:

```text
/magicrender bind circle magicrender:entity_arcane_stream
/magicrender bind trail magicrender:entity_arcane_stream
/magicrender bind stream magicrender:entity_arcane_stream
```

Meaning:

- `bind`: resolve the target entity from the player's crosshair.
- `circle`: calls `MagicCircleManager.spawn(effectId, anchor)`.
- `trail`: calls `MotionEffectManager.spawnTrail(effectId, anchor)`.
- `stream`: calls both trail and circle spawn methods.
- `effectId`: loaded effect config id, for example `magicrender:entity_arcane_stream`.

These commands are client commands. They are intended for local visual testing and do not broadcast the effect to other players by themselves.

## Anchor Policy

Config describes what the effect looks like. Code decides where it attaches.

Supported anchors in the first implementation:

- `TrailAnchor.Entity(entityId, offset)`: follows an entity with optional offset.
- `TrailAnchor.WorldPoint(position)`: fixed world point.

This separation keeps configs safe: a config author can change width, color, lifetime, and limits without selecting arbitrary entities or touching game logic.

## Compatibility Policy

Trail and Beam belong to the first layer: world-space effects.

They do not require screen-space post effects or an offscreen framebuffer. They render through Fabric world render events after translucent geometry, use camera-relative vertices, keep depth test on, and disable depth writes. Iris/Sodium presence is treated as environment information only; disabling visual features remains a manual config decision.
